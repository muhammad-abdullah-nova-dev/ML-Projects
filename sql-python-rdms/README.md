A comprehensive repository of relational database design, third-normal-form (3NF) normalization, Entity-Relationship (ER) diagrams, ETL automated data pipelines, and analytical SQL reporting queries.

Curated and documented by **M. Abdullah**.

---

## 🗄️ Overview & Concepts Demonstrated

* **Data Modeling & Normalization**: Entity-Relationship modeling, foreign key referential integrity constraints, primary key indexing, and 3NF normalization.
* **ETL Ingestion Pipelines**: Automated extraction of World Bank World Development Indicators (WDI) and enterprise club management data into MySQL using Python, Pandas, and SQLAlchemy.
* **Complex SQL Analytics**:
  - Window functions (`ROW_NUMBER()`, `RANK()`, `LAG()`, `LEAD()`)
  - Multi-table `JOIN` operations (INNER, LEFT, SELF)
  - Aggregations and grouping (`GROUP BY`, `HAVING`)
  - Common Table Expressions (CTEs) and subqueries
* **Database Deliverables**: Includes country club membership management system schemas, payments tracking, event booking models, and administrative reporting dashboards.
